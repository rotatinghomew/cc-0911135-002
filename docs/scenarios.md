# 业务演练

|情景|源端设置|接收端结果|
|---|---|---|
|断流|cutOnce=true|部分文件不进入 sealed，重启可用验证器协商续接|
|同名换版|中断后 version=2|不能拼接旧字节，废弃原因可查|
|弱 ETag|weak=true|不能仅凭弱验证器复用旧分片|
|忽略范围|ignoreRange=true|完整 200 不附加在分片尾|
|区间矛盾|wrongRange=true|206 状态不能掩盖 Content-Range 错误|
|越界|本地分片长度超过源长度|416 触发核对，不当作接收成功|
|摘要错误|corrupt=true|同大小坏包拒封存，其他附件仍可独立完成|
|异常退出|在正式重命名后、回执写入前退出|恢复时验证孤立文件与业务归属，不重复封存|
|越域跳转|external=true|未允许的主机没有实际请求|
